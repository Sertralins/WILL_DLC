## 修复内容

1. 条件解析完整消费输入，不因 && / || 短路漏掉右侧；非法语法、参数、未知函数不命中。
2. CURRENT 查询指定行的当前结局；ELLE/ACHIEVE 查询指定行历史；READ/STORY 接入真实状态。
3. 存档结构和版本检查、临时文件写入、有效旧档备份、坏主档恢复、写失败返回；双坏档保留原文件。
4. GameState 统一进度来源与派生索引，读档恢复 S 评级；声望按每个结局首次达成奖励，旧档总额保留。
5. 决定倒计时冻结卡片、返回、重置和重复提交；拖动中不提交；无效落点归位；同栏放置不重复 add_child。
6. 结算显示应用删除；重试保留排列并恢复原句；跨栏变化按实际所在行重放，被替换字条展示新正文。
7. 地图不再凭历史 CHANGE 将仍能重试的结局标为不可达；正常回地图不重新读旧档覆盖内存进度。
8. 数据校验与运行时共用条件语法，检查行数、order、变体、跨关条件目标和资源路径；修复变体引用后定义行的顺序依赖。
9. 移除双列模板与正式场景的重复根 UID，关卡索引移除尾逗号。
