# 「决定」按钮后的倒计时旋转时钟 —— Godot 实现方案

> 基于对游戏素材与 MonoBehaviour 数据的逆向分析（2026-08-24）
> 素材位置：`_extracted\textures\sharedassets0\sp_clock*.png`
> ⚠️ 素材图本身是游戏版权资产，实际使用时请自己重画（机制不受版权保护）

---

## 1. 逆向分析结论

### 1.1 素材结构（6 张图）

| 素材 | 实际内容 | 用途 |
|---|---|---|
| `sp_clock1.png` | 圆形钟面 + 顶部**数字"1"** + 右侧小标签 | 倒计时状态 1 |
| `sp_clock2.png` | 同钟面 + 顶部**数字"2"**（仅顶部区域不同，10487 像素差异） | 倒计时状态 2 |
| `sp_clock3.png` | 与 clock1 **逐像素相同** | 复用 clock1 的图 |
| `sp_clock12.png` | 另一套 UI 的钟面（932×940 有效区域） | 其他场景 |
| `sp_clock22.png` | 与 clock12 相同 | 同图副本 |
| `sp_clock32.png` | 与 clock12 相同 | 同图副本 |

所以实际只需 **2 张有差异的图**：clock1（数字 1）和 clock2（数字 2），其余是副本/复用。

### 1.2 原游戏实现机制（从 MonoBehaviour 数据还原）

时钟是 Unity 的 **UI Image** 组件，关键字段：

```json
"m_Type": 1,              // Image.Type = Sliced（九宫格缩放）
"m_FillMethod": 4,        // = Radial360（径向 360° 填充）★ 核心
"m_FillAmount": 1.0,      // 填充比例（动画驱动：1.0 → 0.0 倒计时）
"m_FillClockwise": 1,     // 顺时针
"m_FillOrigin": 0         // 起始角 = BottomLeft
```

**结论**：倒计时转盘 = 一张钟面图 + **Radial360 径向填充动画**（FillAmount 随时间递减），没有真正的"指针"，靠扇形的末端边线形成"扫描"视觉效果。

## 2. Godot 实现方案

Godot 没有现成的 Radial360 UI 组件，用 **CanvasItem Shader** 实现（方案 A，推荐），或用 `_draw()` 程序化绘制（方案 B）。

### 2.1 方案 A：Shader 径向填充（推荐）

#### ① 着色器 `radial360.gdshader`

```glsl
shader_type canvas_item;

// 填充比例 0.0（全空）~ 1.0（全满）
uniform float fill_amount : hint_range(0.0, 1.0) = 1.0;
// 起始角度（弧度）。Unity FillOrigin=BottomLeft 对应 -135° = -2.356
uniform float start_angle : hint_range(-3.14159, 3.14159) = -2.356;
// 顺时针
uniform bool clockwise = true;

void fragment() {
    vec2 dir = UV - vec2(0.5, 0.5);
    float angle = atan(dir.y, dir.x);       // -PI ~ PI

    // 计算该像素相对起始角的顺时针偏移（0 ~ 2PI）
    float a = angle - start_angle;
    if (clockwise) {
        a = -a;
    }
    a = mod(a, 6.283185307);

    // 可见区域：从起始角顺时针扫过 fill_amount 圈
    // fill_amount=1.0 全显；递减时扇形收缩
    float visible = fill_amount * 6.283185307;
    if (a > visible) {
        discard;
    }
    COLOR = texture(TEXTURE, UV);
}
```

**效果说明**：
- `fill_amount = 1.0`：整张钟面完整显示
- `fill_amount = 0.5`：只剩一半（顺时针方向的一半）
- `fill_amount = 0.0`：完全消失
- 扇形的边界线就是"指针"——它会随动画顺时针扫过钟面

**如果想反过来**（扇形展开：0 → 1 显示越来越大的扇面），把 `if (a > visible)` 改成 `if (a < visible)` 并在下方加一段让另一侧也不显示即可（或调整公式），取决于你要的视觉方向。

#### ② 时钟节点 `decide_clock.gd`

```gdscript
class_name DecideClock
extends TextureRect

const CLOCK_FRAMES := [
    preload("res://art/clock_1.png"),   # 数字 1 帧（自己重画）
    preload("res://art/clock_2.png"),   # 数字 2 帧
]

@export var duration: float = 3.0       # 倒计时总时长
@export var start_angle: float = -2.356 # 与 shader 一致
@export var clockwise: bool = true

var _mat: ShaderMaterial

func _ready() -> void:
    # 创建 shader 材质
    _mat = ShaderMaterial.new()
    _mat.shader = preload("res://shaders/radial360.gdshader")
    _mat.set_shader_parameter("start_angle", start_angle)
    _mat.set_shader_parameter("clockwise", clockwise)
    material = _mat
    visible = false

func play() -> void:
    visible = true
    _mat.set_shader_parameter("fill_amount", 1.0)
    # 倒计时：fill_amount 1 → 0（线性或缓动）
    var tw := create_tween()
    tw.tween_method(
        func(v: float): _mat.set_shader_parameter("fill_amount", v),
        1.0, 0.0, duration
    ).set_trans(Tween.TRANS_LINEAR).set_ease(Tween.EASE_IN)
    await tw.finished
    visible = false
    _on_timeout.emit()

signal _on_timeout
```

#### ③ 数字帧切换（复刻 clock1/clock2 的差异）

原游戏的钟面顶部数字会变（1 ↔ 2）。倒计时过程中切换：

```gdscript
# 在 play() 里，倒计时最后阶段切换数字帧
func _play_number_switch() -> void:
    var tw := create_tween()
    var frames_left := int(ceil(duration))
    for i in range(frames_left, 0, -1):
        # 每隔 1 秒切一帧：数字 1 → 2 → 1 → ...（复刻原游戏只用 2 张图）
        tw.tween_callback(func():
            texture = CLOCK_FRAMES[(frames_left - i) % CLOCK_FRAMES.size()]
        )
        tw.tween_interval(1.0)
```

> 原游戏实际只有两张有差异的图（1 和 2），如果你的倒计时是 3 秒，就按 1 → 2 → 1 循环，或者自己画 3 张数字图。

### 2.2 方案 B：`_draw()` 程序化绘制（无 shader 依赖）

如果不想写 shader，用 Godot 的 `_draw()` 画扇形：

```gdscript
class_name RadialClock
extends Control

@export var fill_amount: float = 1.0 :
    set(v):
        fill_amount = v
        queue_redraw()

var clock_tex: Texture2D = preload("res://art/clock_1.png")

func _draw() -> void:
    # 1) 先画完整钟面（作为底图被裁剪）
    draw_texture_rect(clock_tex, Rect2(Vector2.ZERO, size), false)
    # 2) 用 clip 把超出扇形的部分遮掉（Godot 4.3+ 支持 draw_set_transform 无 clip）
    #    替代做法：画一个"剩余区域"的不透明遮罩
    var n := 64                      # 多边形精度
    var pts := PackedVector2Array([size / 2.0])
    var sweep := fill_amount * TAU
    for i in range(n + 1):
        var a := sweep * float(i) / float(n) - PI / 2.0  # 从顶部开始
        pts.append(size / 2.0 + Vector2(cos(a), sin(a)) * size.length())
    # 画出"未填充"区域的遮罩：多边形 = 全圆 - 扇形，复杂；
    # 更简单：扇区外的部分用反向多边形遮罩
```

**方案 B 的简化版**：不用"裁剪已画好的钟面"，而是**分层**：
- 底层：暗色钟面（未激活状态）
- 上层：亮色钟面 + 扇形遮罩动画（shader 还是绕不开……）

> 结论：**推荐方案 A（shader）**。Godot 的 `_draw()` 无法做「图像裁剪为扇形」，方案 B 只能画纯色扇形（`draw_colored_polygon`），除非再叠一层 shader。shader 方案 20 行代码搞定，性能最好。

### 2.3 指针与额外装饰

从素材看钟面右下角有指针状标记，被径向填充遮罩自然扫过。如果你想强化"时钟"感：

```gdscript
# 独立的指针节点，倒计时期间快速旋转（模拟时钟加速）
var needle: Control
func _play_needle() -> void:
    var tw := create_tween()
    tw.tween_property(needle, "rotation", TAU * 3.0, duration)
        .set_trans(Tween.TRANS_LINEAR)
```

指针与扇形边界对齐时视觉最协调：把指针角度 = `start_angle + (1.0 - fill_amount) * TAU * (1 if clockwise else -1)` 每帧同步即可。

## 3. 完整流程（点「决定」→ 倒计时 → 结算）

```gdscript
# level_controller.gd 中的调用流程
func _on_decide_pressed() -> void:
    # 1) 禁用所有句子拖拽（锁定信件）
    lock_letter(true)
    # 2) 显示时钟并播放倒计时
    clock.visible = true
    clock.play()                       # fill_amount 1→0 + 数字帧切换
    # 3) 倒计时结束 → 结算
    await clock._on_timeout
    var ending := condition_engine.evaluate(level.conditions)
    apply_ending(ending)               # 结局句子替换（见数据 Schema 文档 §4.3）
    clock.visible = false
    lock_letter(false)
```

## 4. 参数速查（复刻原游戏手感）

| 参数 | 原游戏值 | 建议 |
|---|---|---|
| 填充方向 | 顺时针（FillClockwise=1） | clockwise=true |
| 起始角 | BottomLeft ≈ **-135°** | start_angle = -2.356 |
| 倒计时时长 | 未知（推测 2~4 秒） | 3 秒线性 |
| 数字帧 | 2 张（1 和 2） | 按秒切换 |
| 缩放方式 | Sliced 九宫格 | TextureRect `stretch_mode = STRETCH_KEEP_ASPECT_CENTERED` |
